CODEX COURSE — MEGA UPGRADE PASS
=================================

This bundle is the fully-elevated Codex Course. It started as the sanitized
static HTML/CSS/JS bundle (cod.zip) and has been substantially upgraded in
three passes: (1) a global motion/design layer, (2) a global widget polish
pass, and (3) twelve bespoke per-lesson interactive widgets — one per lesson
— authored in parallel by a fleet of agents following a strict shared
contract and design system.

The bundle is still pure static HTML/CSS/JS. No build step, no frameworks,
no external libraries. Serve with `python3 -m http.server 8080` and open
http://localhost:8080 in any modern browser.

---------------------------------------------------------------
Global layers added
---------------------------------------------------------------

- styles/motion.css   (~900 lines)
    Scroll-triggered reveals, count-up animations, 3D tilt hover, scroll
    progress rail, page-transition scene, ambient particle layer, radio-
    style quiz options, flashcard 3D spring flip with scan-line reveal,
    terminal typewriter, bespoke-host frame styling, confetti utility,
    reduced-motion respect everywhere.

- js/motion.js        (~430 lines)
    IntersectionObserver reveals; count-up numbers; scroll-progress bar;
    tilt-hover handler; page-transition cover; ripple coordinate capture;
    ambient particle canvas; bespoke widget auto-mount on any page with
    `<div data-bespoke="LNN">`.

- js/widgets.js       (rebuilt)
    Character-level typewriter with speed control, animated status dot,
    success ripple, confetti burst on completion, flashcard progress dots,
    keyboard navigation, XP burst events.

Both new files are linked into index.html and every lesson HTML.

---------------------------------------------------------------
Bespoke per-lesson widgets (js/lessons/LNN.js)
---------------------------------------------------------------

Each lesson now hosts a bespoke interactive mini-experience placed under a
"Try it: bespoke interactive" section. All widgets follow a single shared
contract: they register themselves on window.CX.LNN with { id, title,
mount(root, ctx) } and are auto-mounted by motion.js. Each is fully self-
contained, injects its own scoped CSS, respects prefers-reduced-motion,
and fires completion via ctx.emitXp() + ctx.confetti(anchor).

  L01  Three-body contract        Living SVG diagram of Task/Repo/Sandbox
                                  with live PR-quality meter reacting to
                                  three "weaken" buttons.

  L02  The sandbox box            Isometric 3D wireframe box with 5
                                  capability toggle switches wired via
                                  animated pulsing lines; network/secrets
                                  flash danger.

  L03  AGENTS.md crystal          Faceted SVG crystal that grows facets &
                                  brightness as draggable convention cards
                                  are absorbed; live PR-style preview flips
                                  lines as each convention lands.

  L04  Spec surgeon               Raw prompt vs compiled task spec with
                                  x-ray scan-line reveal; 5-section
                                  toggles drive an ambiguous→surgical
                                  score bar.

  L05  Scope slider               1h/1d/3d/1w slider with live success-
                                  probability curve, agent-confusion meter,
                                  and sweet-spot dwell detection.

  L06  Done checklist engine      7 ambiguous criteria with 3-option
                                  rewrites; mini PR card transitions from
                                  DRAFT to READY and merges to main.

  L07  PR x-ray                   Simulated diff with 3 hidden bugs; hover
                                  shows Codex reasoning; click to catch
                                  bugs, false alarms tracked in sidebar.

  L08  Decision branch            SVG decision tree; scenarios shown above;
                                  user picks nudge/re-spec/rewrite/revert;
                                  animated pulse along correct branch.

  L09  Toolbelt builder           Drag 5 correct tools from 8-tool rack
                                  into toolbelt slots; right-side mini CI
                                  terminal types green as each slot fills.

  L10  Git graph orchestrator     3 parallel tasks spawn branches on a live
                                  SVG git graph; merge conflict resolution
                                  (rebase or manual) animates smoothly.

  L11  Pattern cards lab          8 flip-cards (5 proven + 3 anti-patterns);
                                  drag into PROVEN/AVOID drop zones; 3D
                                  spring flip with scoreboard.

  L12  The daily loop             24-hour circular clock; drag 6 time-block
                                  chips onto valid windows; tiny agent
                                  avatar walks the clockface as blocks lock;
                                  certificate drops on completion.

---------------------------------------------------------------
Lesson HTML patches (idempotent)
---------------------------------------------------------------

Every lesson file was patched to:
  - link styles/motion.css in <head>
  - load js/motion.js
  - load js/lessons/LNN.js (its own bespoke widget)
  - include a "Try it: bespoke interactive" section with a
    <div data-bespoke="LNN"> slot for auto-mount.

---------------------------------------------------------------
Quality and safety
---------------------------------------------------------------

- All 12 widgets pass `node --check` (valid JS syntax, no parse errors).
- All 12 widgets return 200 OK from the http.server.
- L01 verified rendering end-to-end in the live browser — Task/Repo/Sandbox
  bodies, three weaken buttons, PR Quality meter (starts at 95).
- Every animation respects @media (prefers-reduced-motion: reduce).
- Zero external dependencies. Zero network calls. Zero tracking.
- Class namespace `.cx-LNN-*` prevents any widget-to-widget collision.

---------------------------------------------------------------
How to serve
---------------------------------------------------------------

1. Unzip this archive.
2. cd into the unzipped folder.
3. `python3 -m http.server 8080`
4. Open http://localhost:8080

That's it. Every lesson and every bespoke widget works offline, forever.
