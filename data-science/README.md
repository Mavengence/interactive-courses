# Data Science Fundamentals — Interactive Course

> From distributions to deployment, one live simulator at a time.

A 13-chapter animated course covering the full data science loop. No signup, no install — runs entirely in your browser.

---

## Chapters

| # | Title | Topics |
|---|-------|--------|
| 01 | Fundamentals | Sample vs. population, Central Limit Theorem |
| 02 | Explore | Distributions, outliers, correlation |
| 03 | Clean | Missingness, imputation, scaling, leakage |
| 04 | Feature | Encoding, interactions, selection |
| 05 | Model | Bias/variance tradeoff (live) |
| 06 | Evaluate | Confusion matrix, ROC/PR curves |
| 07 | Interpret | SHAP, feature importance, LIME |
| 08 | Experiment | A/B testing, statistical power, MDE |
| 09 | Causal | DAGs, confounders, Difference-in-Differences |
| 10 | Peeking & CUPED | P-hacking, multiple testing corrections |
| 11 | Deploy | Drift detection, monitoring, retraining |
| 12 | Capstone | Fraud detection end-to-end |

---

## How to Run

```
Open index.html in any modern browser.
No npm, no build step.
```

That's it. All dependencies are loaded from CDN.

---

## Tech Stack

- **React 18** — via CDN (no bundler required)
- **Babel Standalone** — in-browser JSX compilation
- **Pure CSS animations** — no animation libraries
