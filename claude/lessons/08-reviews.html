lesson 08 · advanced

Claude for
Code Review & PRs.

Your tireless, slightly-pedantic reviewer. Use it before humans, not instead of them.

⏱ 9 min◆ 3 interactives✦ +55 XP

Claude reads diffs. It notices naming inconsistencies, missing null checks, tests that don't actually test the thing. It also notices subtext — the "this PR claims to be a refactor but changes behavior" kind of notice.

The trick is prompting it like a teammate, not a linter. That means: give it the author's stated goal, the team's conventions, and a clear bar for what counts as a finding.

◆
Heads up on newer Claudes. If your review prompt says "only report high-severity issues" or "don't nitpick," recent Claude models follow that instruction more faithfully than older ones did. They may investigate just as deeply, find the same bugs, and then — by your own rule — not report the ones below your bar. If your review volume drops suddenly after a model upgrade, loosen the filter before assuming a regression.

The review prompt template

You are reviewing a PR as a staff engineer on the team.

CONTEXT
- Repo: <what the project does, one line>
- Conventions: <link CLAUDE.md or paste summary>
- Author's stated goal of this PR: <paste their description>

DIFF
<paste the diff>

TASK
Review the diff. For each issue, emit:
- severity (blocker | nit | question)
- file:line
- what you'd change and why, in one sentence

Focus on:
1. Does the code do what the description claims?
2. Correctness, especially edge cases and error paths.
3. Tests: are they exercising the change or just present?
4. Consistency with existing conventions in the repo.

Do NOT:
- Rewrite the code.
- Comment on style unless it breaks a convention.
- Pad the review with praise.

Three times it earns its keep

before you push

Paste your own diff, ask for a staff-level review. Catches things you'll be embarrassed by later.

on a big diff

Before reading 2,000 lines yourself, ask Claude for a call-graph summary and a list of behavioral changes.

across the repo

"Are there other callers of this function I missed?" — paste the call sites, let Claude reason about ripple.

Try it

Paste a small diff (real or made-up) and ask Claude to review it using the template.
